# 紫鸢 · 个人名片

一个以「名片」为概念的个人主页，采用淡紫色为主色调，整体风格简洁干净且富有设计感。页面以单个 HTML 文件交付，所有样式、脚本与背景图片均内置于文件中，双击即可在浏览器中打开。

---

## 功能特性

### 视觉设计

- **名片式布局**：页面内容整合为一张圆角矩形名片，毛玻璃质感（backdrop-filter），悬浮于兰花纹背景之上
- **主色调**：淡紫色 `#9b7edc`，搭配辅助色浅紫 `#c5b3ec` 与绿色 `#8fbfa3`
- **SVG 头像**：以色块与线条手绘的简约抽象鸢尾花头像，呼应「紫鸢」主题，无需外部图片
- **渐变文字**：昵称「紫鸢」采用渐变色填充，作为页面核心视觉标识

### 响应式适配

| 设备 | 宽度范围 | 布局方式 |
|------|----------|----------|
| 电脑端 | ≥ 768px | 名片左右分栏横版 |
| 手机端 | < 768px | 名片上下堆叠竖版 |
| 大屏 | ≥ 1200px | 加宽名片并增大内边距 |

- 最小支持宽度 320px，所有内容不溢出屏幕
- 使用 `clamp()` 函数实现字号流式缩放

### 交互动画

1. **页面加载动画**：名片淡入上浮入场
2. **日夜模式切换**
   - 右上角滑动胶囊开关
   - 切换时页面颜色、背景、阴影均平滑过渡（0.45s cubic-bezier 缓动）
   - 开关旋钮带弹性回弹动画
3. **兴趣标签交互**
   - 悬停时标签上移，图标轻微放大旋转
   - **纯音乐**标签：下方展开歌单（arrival of the birds、origin reprise）
   - **读书**标签：下方展开书单（红楼梦、长安的荔枝、追系统的人）
   - 展开内容采用绝对定位浮层，不影响名片尺寸，避免布局抖动
   - 列表项依次淡入，分割线从中心向两侧展开
4. **联系信息交互**
   - 默认只显示「联系我」按钮
   - 悬停时按钮上移，下方浮层淡入邮箱与电话
   - 分割线缓缓展开，移开后原样复原

### 无障碍支持

- 语义化 HTML5 标签（`<main>`、`<section>`、`<footer>`、`<button>`）
- 所有交互元素支持键盘 Tab 聚焦
- `aria-haspopup`、`aria-expanded`、`aria-label` 等属性
- `prefers-reduced-motion` 媒体查询，尊重减少动画偏好

---

## 技术栈

- **HTML5**：语义化标签结构
- **CSS3**：CSS 变量、Flexbox、`backdrop-filter`、`clamp()`、动画与过渡
- **内联 SVG**：头像、图标、背景纹理均为 SVG，零外部资源
- **原生 JavaScript**：日夜模式切换、`aria-expanded` 状态同步
- **Base64 Data URI**：背景图片内嵌为 base64，实现单文件交付

## 使用方式

### 直接打开

双击 `index.html`，在任意现代浏览器中打开即可。

### 本地服务器（可选）

```bash

# 然后访问 http://localhost:8080/index.html
```
